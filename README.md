# Kimi's Personal Blog

- 使用 Hexo 搭建, 主題 Fluid
- 主要內容為技術筆記與心得分享紀錄

#### 相關文件

[Fluid 說明](https://hexo.fluid-dev.com/docs/)

#### 安裝套件

`npm install`

#### 新增文章

`npm run new -- "文章標題"`

#### 本機預覽

`npm run server`

啟動後預設可在 `http://localhost:4000` 瀏覽，儲存文章時會自動重新整理。

#### 建置靜態檔案

`npm run build`

#### 部署

`npm run deploy`


#### 清除快取

`npm run clean`
