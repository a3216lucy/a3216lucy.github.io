Jest 單元測試入門：生命週期與 Mock Function

Jest 是常見的 JavaScript 與 TypeScript 測試框架。除了撰寫斷言外，最常用的能力是安排測試生命週期，以及用 mock 隔離 API、資料庫或其他外部依賴。
